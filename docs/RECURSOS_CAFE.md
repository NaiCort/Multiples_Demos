# Recursos de Ladera

Las fuentes y fotografías de Ladera se sirven desde `public/cafe`; la demo no carga recursos externos.

| Archivo | Origen | Licencia |
|---|---|---|
| `archivo-latin.woff2` | Archivo (Omnibus-Type), subconjunto latino variable de `@fontsource-variable/archivo` 5.3.0, ejes de peso y anchura | SIL Open Font License 1.1, `LICENSE-archivo.txt` |
| `source-serif-4-latin.woff2` | Source Serif 4 (Adobe), subconjunto latino variable de `@fontsource-variable/source-serif-4` 5.3.1 | SIL Open Font License 1.1, `LICENSE-source-serif-4.txt` |

Los alias CSS `Ladera Sans` y `Ladera Serif` aíslan su uso en esta demo. Las curvas de nivel se generan en el navegador y no reproducen el terreno de ninguna finca real.

## Fotografías (V4.3.5)

Once fotografías de [Wikimedia Commons](https://commons.wikimedia.org/), descargadas el 13 de noviembre de 2026, reducidas a 1280 px y 640 px y convertidas a WebP sin recortes ni retoques. `public/cafe/fotos/fotos-origen.json` registra para cada una el título, la página, el autor, la licencia, la URL de descarga, las medidas y la huella SHA-256. La página `/cafe/creditos` muestra autor, licencia y enlace de cada foto.

Licencias: CC0 (latte, cortado, gotero), dominio público (secado), CC BY 3.0 (cerezas) y CC BY-SA 2.0, 3.0 y 4.0 (interior, salón, espresso, tostador, escala de tueste, ventana). Las CC BY y CC BY-SA exigen atribución, cubierta por la página de créditos.

Las fotos ilustran el ambiente de un café; no muestran a Ladera, que es ficticio, ni lugares de Xalapa (la ventana es de San Gimignano, Italia, y no se presenta como Veracruz). Para un cliente real deben sustituirse por fotos propias del negocio.
